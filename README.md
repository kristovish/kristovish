# KRISTOVISH

**Creative technologist, founder, and world-builder based in Chile.**

I create original digital worlds, interactive systems, visual identities, and experimental products that connect technology, design, and storytelling.

## Currently building

### Moonlight

Moonlight began as an online Luanti/Minetest world and community. I am now documenting its systems, lore, visual language, and future direction as an original interactive universe.

## Focus

* Creative direction and worldbuilding
* Interactive experiences and game systems
* Luanti/Minetest modding
* AI-assisted prototyping
* Brand and product experimentation

## Selected work

* [Flower Bushes](https://github.com/kristovish/lady_k-s_flower_bushes) — A Luanti/Minetest mod adding soil-dependent flower bushes, originally created for Moonlight Falls.
* [Kristovish Media Player](https://github.com/kristovish/kristovish-media-player) — A responsive browser-based radio player.
* [Hungry Panda](https://github.com/kristovish/fake_panda_pet) — A playful drag-and-drop browser experiment.
